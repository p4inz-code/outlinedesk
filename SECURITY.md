# Security

Please report security problems privately to **atharva.patil.cg@gmail.com** with the subject "Outlinedesk security". Do not open a public issue for a vulnerability.

Include the version (Settings, About), your operating system, what you did and what happened. A project file that reproduces the problem helps, but do not send files that contain confidential material.

What to expect:
- A reply within 3 business days.
- A fix or a clear answer within 90 days.
- Credit in the release notes if you want it.

What Outlinedesk is designed to protect: your project files stay on your computer, nothing is uploaded, and the optional local connection for AI assistants is reachable only from the same computer. Reports about any of these are especially welcome.
