# Outlinedesk quick start (about 20 minutes)

1. Install. Windows: run the Setup file. Linux: make the AppImage executable and run it. Your first 27 days are a free trial of everything.
2. Create a project. Choose a template (animation short, VFX sequence, game vertical slice) or import your current sheet: File > Import a table accepts CSV and Excel (.xlsx).
3. Set the rules once. Project settings: statuses, working week and holidays, naming pattern for shots, roles, and any custom fields your studio needs (cost, vendor, review round).
4. Plan. Add sequences and shots, set durations and dependencies. Dates, the critical path and late flags update by themselves.
5. Track. Change statuses, set actual dates. The Home page shows progress, late cards, risks, workload and what happened since you last looked.
6. Automate. Home > Automation rules: for example, when Layout is Approved, set Animation to Ready and tell the owner. Use test mode first.
7. Work as a team. Project > Share as a team project puts the plan in a shared folder (network drive, or a folder synced by git, Perforce, Syncthing). Everyone opens the same folder; changes merge and conflicts are listed.
8. Report. File > Export, or the report command for a weekly status without opening the app.
9. Activate. Settings > Licence: paste the key from your e-mail.

Outlinedesk never stores your assets. It keeps the plan and links to your files.
