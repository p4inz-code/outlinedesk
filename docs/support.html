Licence key problems

  • Open Settings, then Licence, and paste the whole key, starting with DESK-. Copy the full line without spaces added at the ends.
  • If it says the key is not valid, paste the check code beside the key too. It points out a mistyped character.
  • If your plan ended, the app is read-only. Enter your renewal key to edit again.
  • Still stuck? Use "Copy support info" on the Licence page and paste it into your email. It never contains the key.

Install problems

  • Windows says the publisher is unknown: choose More info, then Run anyway. The installers are not code-signed yet.
  • Your antivirus blocks it: check the SHA-256 value on the Download page, then allow it.
  • Linux: make the AppImage executable with chmod +x, then run it. If it does not start, send us your distribution and the message it prints.
  • Not sure which file you have? The checksum checker on the Download page tells you.

Questions about your files

  • The app closed unexpectedly: open it again. It offers the latest autosave, which is never more than two minutes old.
  • You changed something by mistake: Undo, or open the History panel and restore a version.
  • An Excel import went wrong: send us the file and tell us which columns you expected.
  • Settings, then Recovery and backup, lists every saved copy and can restore it as a new file.

Sharing a plan with a team

  • Everyone must open the same shared folder. Check that each person can create files in it.
  • Changes arrive when files sync: seconds on a network drive, minutes with git.
  • If you see a conflict, open the Conflicts list from the Team page and choose which change to keep.
  • Read Teams and private networks for the full setup.

Something else

  • Tell us what you did, what you expected and what happened.
  • Add your version (Settings, About) and your system.
  • A screenshot helps. Please do not send project files that contain confidential material.

Common questions

Where do I enter my licence key?

Settings (Ctrl+,), then Licence. Paste the whole key, including the DESK- start, and choose Activate. The key is checked on your computer with no internet.

My plan ended. Did I lose my work?

No. Outlinedesk becomes read-only: open, view and export everything. Enter a renewal key to edit again.

Windows says the publisher is unknown.

The installers are not code-signed yet. In the SmartScreen window choose More info, then Run anyway. Check the SHA-256 value on the Download page first.

Can several people edit one plan at the same time?

Not live. Teams share the plan through a folder, and Outlinedesk merges changes safely when two people save.

Outlinedesk did not close properly. Where is my work?

Open Outlinedesk again. It offers the latest autosave, which is never more than two minutes old.

Can I import my Excel sheet?

Yes. Use File, then Import a table, choose the Excel or CSV file and map the columns. You can also paste rows copied from a sheet.

Does Outlinedesk send my data anywhere?

No. The only network use is the optional update check. See the Privacy page for details.

Which systems does it support?

Windows 10 and 11, and Linux (x86-64). There is no Mac version yet.

How do I move my licence to a new computer?

Enter the same key on the new computer. A key is not tied to one machine. Use it on as many computers as your plan has seats.

How do I report a security problem?

Email us privately with the subject "Outlinedesk security" and the steps to reproduce it. Please do not open a public issue.
