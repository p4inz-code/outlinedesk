Changelog

What changed, and what is next

Release notes for each version, and an honest roadmap.

1.6.0

Release candidate2 November 2026

The first build meant for outside testers, for Windows and Linux.

  • Custom fields and formulas, Excel import and export, paste from Excel and a column chooser with frozen columns.
  • Local automation rules, checklists, handoffs and approvals, and notifications inside the app.
  • A risk list with one-click fixes, a forecast, workload per person and a Home dashboard.
  • Team folders: share a plan through a folder or a git style sync, and the changes merge.
  • Custom statuses, a working calendar with holiday packs, a status grid and saved views.
  • A recovery area, backups to a second folder and checks that a saved file is complete.
  • A policy file for studios that deploy to many computers, and updates from a signed release feed.
  • New licence price sheet, a Windows installer and a Linux AppImage.

Known limits: changes from other people arrive when files sync, not live. Roles are by convention. The installers are not code-signed yet. There is no Mac version.

Earlier versions

  • 1.5.0, 6 October 2026: timeline view, safer shared folders, a hardened file format and offline review.
  • 1.4.0, 5 October 2026: folder watching, Houdini support, a verified Blender add-on and the website.
  • 1.3.0, 5 October 2026: licence plans, read-only mode and the first key generator.
  • 1.2.0, 4 October 2026: design pass and a richer tour.
  • 1.1.0, 4 October 2026: export, onboarding and accessibility work.
  • 1.0.0, 1 October 2026: the first complete version.

Roadmap

Where it is going

Plans change with what customers need. Nothing here is a promise of a date.

Next

  • Automatic updates tested end to end on installed copies.
  • Pilots of team folders on real studio storage.
  • Real Excel files from more tools.
  • A Linux build verified on more distributions.

Later

  • Plugins for Maya and Unreal Engine.
  • Signed installers.
  • More importers from other trackers.
  • A Mac version when it can be built and tested properly.

Not planned

  • Storing your asset files.
  • Review video and playback.
  • Time tracking and invoicing.
  • A hosted version that holds your project data.
