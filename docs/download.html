Download

Outlinedesk is in release candidate testing. The installers are on the project's release page, github.com/p4inz-code/outlinedesk/releases, with a SHA-256 checksum for each file. Every download starts the 27-day trial.

Request a build

Windows

Windows 10 and 11, 64-bit. Installer (.exe), about 240 MB. It installs for your user only and needs no administrator rights.

Not code-signed yet: in SmartScreen choose More info, then Run anyway.

macOS

Not supported at the moment.

Linux

AppImage, x86-64, about 125 MB. Built and checked on Ubuntu.

Mark the AppImage as executable, then run it.

System requirements

  • 4 GB RAM (8 GB for plans over 10,000 cards)
  • 300 MB disk space
  • A display of 1280 × 800 or larger is comfortable; 800 × 500 is the minimum
  • No internet connection needed, ever

Add-ons

A Blender add-on works today; more integrations are planned. It talks to Outlinedesk on your own computer only.
