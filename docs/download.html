Check your download

Make sure the file is the real one

Each file has a SHA-256 checksum. Work out the value for the file you downloaded, paste it here, and the page tells you whether it matches. This happens in your browser. Nothing is uploaded.

On Windows

Get-FileHash .\Outlinedesk-Setup-1.6.0.exe

On Linux

sha256sum Outlinedesk-1.6.0.AppImage

Paste the 64 character SHA-256 value of your downloaded file.

Good to know

Requirements and answers

  • Windows 10 or 11 (64-bit), or Linux (x86-64). There is no Mac version yet.
  • 4 GB of memory, or 8 GB for plans with more than 10,000 cards. About 300 MB of disk space.
  • A screen of 1280 by 800 or larger is comfortable. 800 by 500 is the smallest it supports.
  • No internet connection is needed to use it. The only network use is the optional update check.
  • A Blender add-on works today. Plugins for other tools are not available yet.
Windows says the publisher is unknown. Is the file safe?

The installers are not code-signed yet, so Windows shows that warning for any new program. Check the SHA-256 value above, then choose More info and Run anyway. We will sign the installers once the project can pay for a certificate.

My antivirus blocked the installer

Unsigned programs are sometimes held for a scan. Check the SHA-256 value, then allow it in your antivirus. If it keeps blocking, email us the antivirus name and the message.

How do I uninstall it?

On Windows, open Settings, then Apps, then Outlinedesk, then Uninstall. Your projects stay where you saved them. On Linux, delete the AppImage file.

Where is my licence key entered?

Open Outlinedesk, go to Settings, then Licence, paste the whole key and choose Activate. The key is checked on your computer, with no internet.
